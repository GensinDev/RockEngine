### 🚀 RockEngine



Custom game engine written in C++ with OpenGL.



\---



#### 📌 About



RockEngine is a custom game engine and editor built from scratch using:



\* C++

\* OpenGL

\* GLFW

\* ImGui

\* CMake



The goal of this project is to learn engine architecture and eventually build a full game (GTA/RDR-like).



\---



#### 🧱 Features



##### Editor



\* Docking UI (ImGui)

\* Viewport rendering

\* Hierarchy panel

\* Inspector panel

\* Asset Browser



##### Rendering



\* OpenGL renderer

\* Framebuffer rendering (Viewport)

\* Depth testing \& face culling

\* Basic cube rendering



##### Scene System



\* Entity system

\* Transform (Position / Rotation / Scale)

\* Scene save/load (.rockscene)



##### Interaction



\* Mouse picking (select objects in viewport)

\* Drag \& Drop (assets → viewport)

\* Editor camera (WASD + mouse)



\---
